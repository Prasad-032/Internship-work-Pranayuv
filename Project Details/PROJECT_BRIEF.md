# 📄 ✅ PROJECT BRIEF (Refined Version)

## 🏢 Business Overview

**Company:** Sri Srinivasa Clean Rooms
**Industry:** Medical Furniture & Clean Room Solutions
**Offering:**

* Medical furniture products
* IoT-enabled healthcare products (via vendor partnership with Pranayuv)
* Focus on durability, quality, and reliability

👉 Important clarity:
They are **B2B vendors**, not direct consumer sellers (this affects UX heavily).

---

## 🎯 Website Goals

The website should:

* Showcase product catalogue
* Enable **bulk order requests / purchases**
* Allow **meeting booking**
* Provide **company + product information**
* Build trust (certifications, achievements)
* Maintain communication with clients

👉 Key actions user should perform:

* Browse products
* Request quote / order
* Contact company
* Book consultation

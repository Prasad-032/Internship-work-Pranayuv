# 1. ORDERING FLOW

**Step-by-step**:

1. User visits product page
2. Clicks “Request Quote” (instead of Buy Now)
3. Fills form:
4. Quantity
5. Requirements
6. Contact details
7. Submit request
8. Company reviews request (Admin side)
9. Company sends quotation
10. User approves → then payment happens

- Bulk orders need negotiation
- Prices may vary
- Customization needed

# 3. PAYMENT FLOW

👉 Hybrid Payment Model

Flow:
1. User requests quote
2. Admin sends price
3. User confirms
4. Then:
 - Option A: Pay online
 - Option B: Receive invoice → pay offline
